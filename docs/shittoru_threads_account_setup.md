## 3. 投稿ドラフト

Threadsの実測傾向にあわせた作り（1投稿1メッセージ・50〜120字・冒頭で言い切る・
問いかけで締めない・絵文字は自然な量）。広告費の具体額と他社批判は入れていない。

## 4. Meta審査の録画に向けた段取り

却下の原因は「権限同意画面が動画に映っていないこと」。認可済みのアカウントだと
同意画面が出ずショートカットになるため、**まだ一度も連携していない新規アカウント**で撮る
のがいちばん確実。この新アカウントはその条件を満たす。

1. アカウント作成（三上さん）
2. Threads Studioに審査用ユーザーでログインし、Connect Threadsまで進める（私）
3. **録画開始 →** Threadsのログイン画面でID/パスワード入力（三上さん）→ 権限同意画面で「許可」
   ※ ここが審査で必須の2要素。私はパスワード入力を代行できないため三上さんが操作する
4. 以降の操作（投稿生成→公開→コメント返信→分析）は私が録画しながら実施
5. threads_manage_replies の実演には**そのアカウントの投稿にコメントが1件必要**。
   別のThreadsアカウント（moveact等）から1件コメントを付けておく
6. 編集・英語キャプション・申請ノート作成・提出準備（私）
7. **提出前に、必須3要素が何秒地点に映っているかをフレーム画像で三上さんに提示**して確認を取る
