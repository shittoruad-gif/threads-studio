## 変えるときの順番（代理店プランを売り始めたら）
1. 契約が入ったら：週次まとめ（月曜9:05）が届くことを確認。VPSの空きメモリと LINE の残量を毎週見る。
2. 代理店クライアント合計 30件 or 有料合計 60：**VPSを8GBへ**（夜間に実施。Coolifyは止めずにConoHa側でプラン変更→再起動）。
3. 有料＋クライアント合計 60：**LINEを月30,000通のプランへ**。
4. メール月2,500通：**Resend Pro へ**。
5. クライアント100件：AGENCY_CLIENT_LIMIT を上げる前に、Threads Studio を別サーバーへ分離。

## 台帳の直し方
- 数字を更新したら日付を添える。基準を変えるときは、理由を1行で書く（例：「9/11 空き19%で警告なしに運用できているため15%を注意ラインに」）。
- 自動監視を足したら「自動監視」列に書く。監視のコードは `server/opsDigestJob.ts`（LINE枠・空きメモリ）。
